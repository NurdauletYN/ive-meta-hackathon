# Rocket studio

Local tester, written this week. Not the Ive product.

```bash
uv run harness ui --port 8765
# http://127.0.0.1:8765/
```

The phone is the product. Token skins appear immediately; optional Flutter web replaces them.

- **3 looks** — three palettes as app screens. Click one to pick it.
- **Build** — spec + guarded files + gate. The phone shows a skin during the wait, then Flutter if **Flutter preview** is on (default).
- **Compare bare** — capsule vs blank `flutter create`, two phones with pass/fail.
